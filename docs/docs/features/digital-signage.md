# Digital Signage Extensions

The reference app explicitly markets to churches, schools, and stores for
signage use cases (menus, bulletins, schedules). Extensions worth considering:

- **Playlist scheduling** — different content at different times/days
- **Remote management dashboard** (web portal) — push content to multiple screens/locations
- **Mixed content support** — insert a PDF flyer, a web page, or an RSS feed slide between photos
- **Multi-screen sync** — several TVs in one building show content in sync

## Related use cases

- Digital photo frame for grandparents
- Restaurant menus, store marketing, church bulletins, school schedules on a TV
