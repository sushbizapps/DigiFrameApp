# Smart Curation / AI

- On-device face grouping so slideshows can be filtered (e.g. "just Mom", "just the kids")
- Auto-generated "On this day" / memories slideshows
- Duplicate and blurry-photo detection to auto-exclude junk shots
- Auto-tagging/scene detection (beach, birthday, pets) to build themed slideshows automatically
- Smart crop/reframe for portrait photos on landscape TVs (saliency detection) to avoid black bars

:::note Privacy
Face grouping and scene detection should run on-device where possible, and
this should be reflected clearly in the app's data-safety disclosures.
:::
