# Reliability & Trust Features

Direct response to the reference app's most common negative reviews (broken
auto-import, manual re-adds required, occasional silent deletion of
photos).

- **Manual "Force full re-sync" button** with a visible progress log, so users aren't left guessing
- **Sync diagnostics/history log** showing what was added/removed and why
- **Local backup before any bulk delete operation**, with an undo window

See also: [Sync Engine architecture](/architecture/sync-engine) for the
underlying design principles (transparency, non-destructive by default,
resumability).
