# Sharing & Collaboration

- Shared/family albums with multiple contributors feeding one frame — supports the "digital photo frame for grandparents" use case
- QR code or simple link letting a family member remotely upload a photo that appears in the frame
- Guest mode for events (wedding, party) — guests text/AirDrop photos in, which get added live to the display

## Accessibility & convenience (related)

- Text-to-speech reading of photo captions/dates for visually impaired users
- Large-button "simple mode" UI for elderly users controlling the frame
- Multi-language overlay support for date/weather
