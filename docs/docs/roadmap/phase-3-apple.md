# Phase 3: iOS + tvOS

**Rough duration:** 2–3 weeks

## Goal

Chromecast sender + Android TV app polish, and Apple platform support to
unlock iCloud Photos users and the "combine Google Photos + iCloud" use case
a reference-app reviewer specifically asked for.

## Deliverables

- [ ] Google Cast SDK sender integration (from Phase 1/2 Android work) + Android TV receiver polish
- [ ] iOS/iPadOS companion app (Swift/SwiftUI)
- [ ] tvOS native slideshow app
- [ ] iCloud Photos integration (pending API validation — see open question below)

## Why now

Unlocks a meaningfully different user base (Apple ecosystem / iCloud) and
directly answers a differentiator identified from reference-app reviews.
See [Apple platform notes](/platforms/ios-tvos).
